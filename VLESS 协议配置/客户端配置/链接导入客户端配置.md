# 链接导入客户端配置

不同客户端对 sing-box 配置的支持程度不同，Linux 客户端通常可以直接使用 sing-box 配置，大部分其他客户端更推荐使用 VLESS 链接导入至第三方客户端使用

# 链接生成

准备信息：

- `UUID`：服务端配置的 UUID
- `服务器 IP/域名`：服务器的 IPv4 地址、IPv6 地址或域名，三者任选其一
- `public_key`：服务端生成的 Reality 公钥
- `short_id`：服务端配置的 Short ID
- `链接备注`：VLESS 链接的备注名称

VLESS 链接：

```text
vless://<替换 UUID>@<替换服务器 IP/域名>:443?type=tcp&security=reality&pbk=<替换 public_key>&fp=chrome&sni=www.apple.com&sid=<替换 short_id>&flow=xtls-rprx-vision#<替换链接备注>
```
